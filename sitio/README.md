# Página web de Isabella

Página de una sola hoja (`index.html`) para que las clientas conozcan a Isabella y le escriban.

- **Encuentra tu rutina**: test de 3 preguntas (piel, qué quiere, cuánto tiempo) que arma una
  rutina de mañana y noche con sus productos y la manda por WhatsApp.
- **Mis favoritos**: productos con foto, para qué sirven y reseñas de la tienda. Sin precios.
- **Aprende conmigo**: los videos del Profe (`agente-educativo/`), en versión liviana.
- **Escríbeme**: arma el mensaje y abre WhatsApp. Gratis, sin servidor.

Todos los mensajes empiezan con "vengo de tu página web", así el agente de comunidad sabe de
dónde llegó la clienta al anotarla en la libreta (origen: página web).

## Lo que falta llenar

Arriba del `<script>` en `index.html`, el bloque `ISABELLA`: número de WhatsApp con código de
país, usuario de Instagram y de TikTok. Y la foto de Isabella en el recuadro "Aquí va la foto".
Mientras falten, la página muestra un aviso de "vista previa".

## Verla

Abre `sitio/index.html` en el navegador. Para publicarla gratis se puede usar GitHub Pages.
